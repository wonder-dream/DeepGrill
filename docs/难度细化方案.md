# 题目难度细化（1-3 → 1-5 + LLM 标注）实施方案

> 状态：已实施 ｜ 日期：2026-08-09

## 1. 目标

难度分级由 1-3 细化为 **1-5**：新题生成时 LLM 按档位定义标注；存量 2225 题（分布 1:362 / 2:1254 / 3:609）用 LLM 全量重标（1-3 无法机械映射）；判分按难度校准期望；前端星级展示。

## 2. 档位定义（LLM 标注依据）

新增 `app/difficulty.py`（零依赖公共模块，generate/judge/migrate 三处复用）：

- `DIFFICULTY_NAMES = {1: 入门, 2: 基础, 3: 进阶, 4: 深度, 5: 专家}`
- `DIFFICULTY_SCALE_TEXT`：五档描述 + 示例题 + 四维判定（广度/深度/权衡/经验依赖）

## 3. 改动清单

### 生成侧（新题，`app/pipeline/generate.py`）

- 两个 prompt（GENERATE/PROJECT）：`difficulty: 1-3 的整数` → `1-5 的整数`，新增第 8/5 条嵌入 `DIFFICULTY_SCALE_TEXT` 作为标注依据
- `_clamp_difficulty`：`max(1, min(3, ...))` → `max(1, min(5, ...))`

### 判分侧（`app/judge/judge.py`）

- 难度行：`难度：{difficulty}（1-3）` → `难度：{difficulty}/5（{档位名}）`
- 新增判分期望校准句：1-2 级答全要点即可高分；3 级须展示权衡；4-5 级须在 depth/completeness 体现方案选型与实战取舍
- `PROMPT_VERSION` → `judge_v5`（测试 `test_prompt_version_frozen` 同步）

### 上传直接模式（`app/web/routes.py` `_tag_direct_questions`）

- prompt 输出 `{stem, tags, difficulty}`，difficulty 钳制 1-5 与 tags 一并回写；失败保持默认 1

### 存量迁移（`scripts/migrate_difficulty.py`）

- 全量 2225 题逐题 LLM 标注（prompt = 档位定义 + 题干 + 标签 → `{"difficulty": 1-5}`）
- 钳制 1-5、非法值跳过保留原值、失败跳过日志、可复跑、每 20 条进度；预计 20-40 分钟
- 跑法：`uv run python scripts/migrate_difficulty.py`

### 前端（`app/web/static/app.js`）

- 新增 `difficultyStars(n)`（★×n + ☆×(5-n)），替换 5 处渲染（题库卡/今日卡/答题页 meta/复习列表/历史列表）
- 顺带清理死代码：`#detail-difficulty` badge（index.html 与 app.js 清空语句，从未被赋值）

## 4. 测试

- `test_generate.py`：钳制断言 5→3 改 6→5
- `test_routes.py` `test_upload_direct_mode_tags_llm`：FakeLLM 输出含 difficulty，断言回写 4 与钳制 9→5
- 全量回归：**265 passed**
