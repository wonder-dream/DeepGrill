# judge 参考检索（Phase 2 §9.3）实施方案

> 状态：✅ 已完成 ｜ 日期：2026-08-08
> 对应 DESIGN.md §9.3：判分时检索库内同类高分回答作为参考答案参照；落地前 hit_rate/MRR 评估

## 1. 目标

判分时检索库内同类题的高分回答，作为"参考答案参照"注入 judge prompt。**评估先行**：text / vector / hybrid 三种检索对比（hit_rate@5 / MRR@5），达标才接 judge。

## 2. 已确认决策

- **接受冷启动**：库内 0 判分记录，空检索自动降级（不注入，行为等同 v2），数据积累后自动生效
- **真实回答优先**：参考内容 = 高分（≥80）会话的 attempts 完整回答；无则 Judgment.reference_answer 兜底
- **评估集 16 条**：真实题库"同知识点改措辞"对 + 语义改写 query（低词汇重叠，检验语义检索而非字面匹配）

- text 评分：2-gram 关键词重叠（词表标签辅助）
- vector 评分：bge-m3 余弦（query encode 一次，复用 Question.embedding；批量补算 NULL）
- hybrid：`vector_weight × vector + (1-vector_weight) × text`，权重评估标定 = 0.8

## 4. judge 升级（v2 → v3）

- `JUDGE_SYSTEM_V3`：新增参考回答段（"仅作标准参照，不要照抄"）
- `PROMPT_VERSION = "judge_v3"`
- `judge(..., reference=None)`：None 时 prompt 不含参考段（降级）

## 5. 调用链

- `routes.py` `_run_answer_job`：判分前 `_reference_for(question, embedder_factory)`（候选=库内高分题，embedder 注入）；chain 路径传 `chain.finish(reference=...)`
- `chain.py` `finish(reference=None)` → judge

## 6. 评估结果（16 条，k=5，真实 bge-m3）

| method | hit_rate@5 | MRR@5 |
|---|---|---|
| text | 0.500 | 0.450 |
| vector | 0.750 | 0.575 |
| hybrid(w=0.5) | 0.688 | 0.531 |
| hybrid(w=0.7) | 0.688 | 0.594 |
| **hybrid(w=0.8)** | **0.750** | **0.596** |

**验收：vector ≥ text ✓，hybrid(0.8) ≥ vector ✓ → 达标上线**（默认 hybrid w=0.8）。
跑法：`uv run python scripts/eval_retrieval.py`（含权重扫描，可复跑）。

## 7. 测试（224 全绿）

- test_judge：reference 注入断言 / 空 reference 无参考段 / 版本冻结 v3
- test_routes / test_chain：判分链路（FakeEmbedder 注入）

## 9. 明确不做

- 向量库（继续 numpy 暴力，千级题量毫秒级）
- 检索结果缓存（判分频率低，实时检索成本可忽略）
- 用户回答语义匹配（query 只用题干）
