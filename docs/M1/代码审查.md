#### 🟡 建议修改
**1. 非 UTF-8 编码的 config.yaml 漏出原始异常**
- 位置：`app/config.py:63`
- 问题：`read_text(encoding="utf-8")` 遇到 GBK/UTF-16 BOM（Windows 记事本默认）抛 `UnicodeDecodeError`（已实证），且 `UnicodeDecodeError` 不属于 `OSError` 未被捕获——违反"全部配置错误归为 ConfigError"契约
- 建议：捕获 `UnicodeDecodeError` → `ConfigError`，提示"请用 UTF-8 编码保存 config.yaml"

**2. `test_environment_variable_takes_precedence_over_dotenv` 断言无意义**
- 位置：`tests/test_config.py:97`
- 问题：`assert True` 不验证任何行为，且配置对象只存变量名，测试未观测到优先级结果
- 建议：断言 `os.environ["LLM_API_KEY"] == "sk-from-env"`（load 后 dotenv 未覆盖）

**3. `test_secrets_read_from_dotenv_file` 可绕过 .env 通过**
- 位置：`tests/test_config.py:50`
- 问题：若开发机全局已设 `LLM_API_KEY`/`NOWCODER_COOKIE`，.env 未被咨询测试也通过，不能证明 .env 加载生效
- 建议：测试内先 `monkeypatch.delenv` 两个变量，强制走 .env 路径
