# 题目分类筛选（题型 + 标签）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 1. 目标

今日题目、历史记录、薄弱点复习三个界面各加**两个筛选下拉**：题型（knowledge/design/project）+ 标签（主题）。纯前端实现，后端零改动（三个接口的 item 均已带 `type` 和 `tags`）。

## 2. 通用设计

- 题型下拉：静态选项（全部 / knowledge 知识题 / design 设计题 / project 项目题）
- 标签下拉：动态生成——当前加载数据 items 的 tags 并集，按出现频率降序 + "全部"
- 共用 helper：`fillTagOptions(selectEl, items)`、`filterByTypeTag(items, type, tag)`（AND）

## 3. 各界面

| 界面 | 改动 |
|---|---|
| 今日 | 统计卡下方加 filter-bar；`state.todayItems` 缓存；筛选变化重渲染 |
| 历史 | 现有 filter-bar 追加题型/标签；`applyFilters` 增加条件（与状态/日期/分数 AND） |
| 复习 | 复习列表视图加 filter-bar（入口页隐藏）；`state.reviewItems` 缓存；筛选变化重渲染 |

## 4. 边界

- 标签选项随数据动态刷新；过滤为空显示"无符合条件的记录"
- 复习页标签筛选：从当前列表 items 的 tags 生成（同列表内再细筛）

## 5. 验证

- `node --check` + 全量 pytest 回归（后端未动）
- 手工：三界面分别筛题型/标签/组合、空态、历史与现有筛选联动
