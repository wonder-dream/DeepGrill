# 旧题标签迁移（LLM 重打）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 1. 背景

词表落地前生成的 151 题含 297 个词表外旧标签（多模态/Netty/RNN 等），不参与分类筛选与复习聚合。人工映射不可行（297 个），采用 **LLM 逐题从词表重打**。

## 2. 脚本 `scripts/migrate_tags.py`

1. 查询全部含词表外标签的题
2. 逐题调用 LLM（便宜生成模型）：题干 + 58 词词表 → `{"tags": [1-5 个词表内标签]}`
3. 代码层词表过滤（上限 5）→ UPDATE questions.tags
4. 幂等：只处理含词表外标签的题；单题失败跳过记录，可重跑
5. 进度日志 + 结束统计

## 3. 范围

- 只处理 151 题；不重算 embedding（基于 stem）
- weak_tags 历史判分不迁移

## 4. 验证

- 词表外标签残留 0、无分类匹配题 0
- 抽查 10 题标签质量；pytest 全量回归

## 5. 成本

151 次 LLM 调用 × 便宜模型 ≈ 几分钟、几毛钱。

## 6. 不做

- weak_tags 迁移；全部题重打；启动自动化
