## 根因确认汇总

| Bug | 根因 | 证据 |
|---|---|---|
| 4. 点今天日期题消失，刷新又回来 | 服务器容器 TZ=UTC，浏览器国内 UTC+8。`/api/today?date=` 按服务器本地零点查 UserPick，而 picks 存服务器本地 `picked_at`；中国时间 00:00-08:00 两边「今天」不同日 → 日期查询空、无 date 路径（`_ensure_today_picks`）能查到 | 与上线前修复计划 B2 同一根因（该计划已定 TZ 修复、未执行） |
| 2. 经常刷新不出来 | ① 静态资源无缓存头：Starlette 1.4.1 StaticFiles 不设 Cache-Control/ETag，部署后浏览器旧 index.html+新 app.js 错配 → JS 崩白屏（交接文档「Ctrl+F5」即此）；② `initAuth` 把任何网络失败/5xx 都当 401 → 跳登录页 | 实测 StaticFiles.file_response 无缓存头；app.js initAuth catch-all → showAuth |
| 1. 回答题目有时候 502 | 用户挂 Clash 系统代理直连公网 IP：代理对上游慢/断返回 502；服务器卡死窗口 = 每次判分参考检索**新建 bge-m3 实例**（~2.3GB），并发答题/上传时 4C8G 打满；WAL 下并发写无 busy_timeout 仍会 locked 卡顿 | `embedder_factory` 每次调用 new `Embedder()`；db.py 无 busy_timeout；用户确认直连 IP+Clash |
| 3. 标签有误 | ① 词表缺 Go/操作系统/Docker 等主题 → GO 函数传参题错标「并发」、Docker 等 29 题标签为空；② 简历确认流前端只回传 stem → `_confirm_project_questions` 落 `tags=[]`，候选标签全丢；③ 判分 weak_tags 可能指向题库无该标签的题 → 复习列表空 + 复习卷「该标签暂无题目」死胡同 | 本库实测：空标签 29 题；upload_confirm 只发 {stem}；review 无题无回退 |

## 修复内容

### Bug 4（点击当前日期题目消失）
1. `docker-compose.yml`：`services.app.environment` 加 `TZ=Asia/Shanghai`（已决策项，本次执行）
2. `app/web/static/app.js`：today 模式点击日历「今天」格 → `loadToday()`（不带 date），根除该 bug 类（不依赖时区）；`showAuth()` 重置 `state.todayDate`

### Bug 2（刷新不出来）
3. `app/web/routes.py` `index()`：`FileResponse` 加 `Cache-Control: no-store`（index.html 永不过期缓存）
4. `app/web/static/index.html`：`app.js`/`style.css` 引用加版本参数 `?v=<git 短 hash>`（部署新代码后自动失效）
5. `app/web/static/app.js` `initAuth`：仅 401 跳登录；网络错误/5xx 显示「连接失败，自动重试中…」并退避重试，不再直接丢登录页

### Bug 1（答题 502）
6. `app/web/routes.py`：默认 `embedder_factory` 改为模块级共享单例（lazy 加载，并发答题/上传只加载一份 bge-m3）
7. `app/db.py`：SQLite 连接事件加 `PRAGMA busy_timeout = 5000`
8. `app/web/static/app.js` `api()`：仅 GET 请求对 502/503/网络错误短退避重试（POST 不重试，防重复判分轮次）；`pollResult` 瞬时错误继续轮询不中断
9. 备注（不改代码）：Clash 规则把 `<服务器IP>` 配直连可根治该链路

### Bug 3（标签有误）
10. `app/tags.py`：词表补常见缺失主题（Go、操作系统、Linux、Docker、K8s、Git、数据库、前端、测试、安全等，归入「后端基础/通用」）
11. 简历确认流保留标签：`app/web/static/app.js` upload_confirm 回传 tags/difficulty + `app/web/routes.py` `_confirm_project_questions` 落库
12. 复习死胡同回退：`/api/review` 与 `/api/review/paper` 该标签无题时回退到同分类（TAG_CATEGORIES）标签题目，返回 `fallback` 标记；前端提示「该标签暂无题目，展示相关分类题目」
13. 一次性脚本 `scripts/retag_empty_tags.py`：对空标签题按新词表 LLM 补标（复用 `_tag_direct_questions` prompt 模式，可复跑）
