## 2. 部署执行（Workbench）

### 2.1 上传两个文件到 /root/

- `deploy_package.tar.gz`（Workbench 文件上传）
- `interview_backup_20260813_165500.zip`（Workbench 文件上传）

### 2.2 建目录 + 解压代码

```bash
mkdir -p /opt/interview-assistant
tar -xzf /root/deploy_package.tar.gz -C /opt/interview-assistant
```

### 2.3 从零创建 .env（全新实例无旧 .env）

```bash
cd /opt/interview-assistant
cp .env.example .env
nano .env
```

必填项（全部要填）：

```
LLM_API_KEY=sk-xxx                 # LLM 密钥
SMTP_HOST=smtp.163.com             # 163/QQ 邮箱 SMTP
SMTP_PORT=465
SMTP_USER=你@163.com               # 发件邮箱
SMTP_PASS=你的授权码               # 非登录密码，邮箱设置开 SMTP 拿授权码
OWNER_EMAIL=你@163.com             # owner 管理员账号（与 SMTP_USER 可同）
OWNER_PASSWORD=强密码
```

可选：`NOWCODER_COOKIE`（牛客 cookie，不配则该源安静停用）、`MAX_USERS=20`（注册名额）。
`ENABLE_DOCS` 不配（生产默认禁 /docs）。

### 2.4 一键部署（装 Docker + 构建 + 启动，首次约 5-10 分钟）

```bash
cd /opt/interview-assistant
bash deploy.sh          # 内部：装 Docker → 检查 .env → docker compose build → up -d
docker compose logs -f app    # 确认无报错，看到 "seeded owner user" 日志即 OK
```

### 2.5 导入本地备份（Web）

1. 浏览器打开 `http://<服务器IP>:8000` → 用 **OWNER_EMAIL/OWNER_PASSWORD** 登录（启动时已种 owner）
2. 上传页 → 数据备份 → **导入备份** → 选择 `interview_backup_20260813_165500.zip`
3. 导入完成后**重启容器**（导入原子替换了整库，users 表被本地 0 用户覆盖，需重启重种 owner）：

```bash
docker compose restart app && docker compose logs -f app   # 看到 "seeded owner user" 即恢复
```

### 2.6 验证清单

```bash
docker compose exec -T app python -c "import sqlite3; c=sqlite3.connect('/app/data/interview.db'); print('questions:', c.execute('SELECT COUNT(*) FROM questions').fetchone()[0]); print('chunks:', c.execute('SELECT COUNT(*) FROM knowledge_chunks').fetchone()[0]); print('tags:', c.execute('SELECT COUNT(*) FROM tags').fetchone()[0]); print('users:', c.execute('SELECT COUNT(*) FROM users').fetchone()[0])"
```

1. `docker compose logs` 无报错；`/api/tags` 返回 16 分类 114 标签
2. 重新用 OWNER_EMAIL 登录 → 答题/判分（首次判分触发知识索引构建，1-2s）→ 参考回答带知识细节
3. 浏览器强刷：日历/统计面板/复习/收藏/审核页正常

## 5. 注意事项

- 打包必须排除 `.env`（含真实 API key/cookie）；本包已验证
- 导入备份 = **原子整库替换**：导入后必须重启一次容器以重种 owner（`_seed_owner_if_configured` 仅启动时执行）
- 首次判分触发知识索引构建（自动）；MinerU 模型首次上传 PDF 时下载（自动）
- 知识库数据在 DB 内（备份 zip 天然携带），无需单独同步文件
- 阿里云安全组需放行 8000 端口（入方向），否则公网访问不通
