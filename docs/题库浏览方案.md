# 题库浏览页（分页 + 筛选 + 侧边栏入口）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-09

## 1. 后端：`GET /api/bank`

```
GET /api/bank?page=1&page_size=20&type=&category=
```

- page 默认 1；page_size 默认 20 上限 50；type（knowledge/design/project）；category（词表分类名）
- 响应：`{total, page, page_size, total_pages, items: [{id, stem, type, difficulty, tags, done}]}`
- 排序 id 倒序；done 复用 `_latest_judgment_by_question`
- 校验：非法 page/type/category → 400；超页返回空 items

## 2. 前端

- 侧边栏加「题库」入口（今日下方）
- `#view-bank`：筛选栏（题型+分类，变化重置第 1 页）+ 档案抬头（共 N 题）+ 卡片列表（已答/待做徽标）+ 分页控件（上/下页 + 页码信息，边界禁用）
- app.js：`show("bank")` → loadBank；`state.bankPage`；点击开答（returnTo="bank" 返回恢复页码）；`loadTagCategories` 补填第 4 个分类下拉
- style.css：`.bank-pager`
