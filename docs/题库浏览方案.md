# 题库浏览页（分页 + 筛选 + 关键词搜索 + 侧边栏入口）实施方案

> 状态：已实施 ｜ 日期：2026-08-09

## 1. 后端：`GET /api/bank`

```
GET /api/bank?page=1&page_size=20&type=&category=&q=
```

- page 默认 1；page_size 默认 20 上限 50；type（knowledge/design/project）；category（词表分类名）；q（关键词，2026-08-09 新增）
- 响应：`{total, page, page_size, total_pages, items: [{id, stem, type, difficulty, tags, done}]}`
- 排序 id 倒序；done 复用 `_latest_judgment_by_question`
- 校验：非法 page/type/category → 400；超页返回空 items
- **关键词搜索（q）**：LIKE 子串包含，大小写不敏感（ASCII 小写化）；匹配范围为题干 stem + 标签 tags（任一命中即保留）；与 type/category 可组合；`strip()` 后空串视为无过滤。技术选型：LIKE 子串而非 FTS5/语义检索（2189 题量级全扫毫秒级，中文子串天然可用，无同义词/相关性排序需求）

## 2. 前端

- 侧边栏加「题库」入口（今日下方）
- `#view-bank`：筛选栏（题型+分类+搜索框，变化重置第 1 页）+ 档案抬头（共 N 题）+ 卡片列表（已答/待做徽标）+ 分页控件（上/下页 + 页码信息，边界禁用）
- app.js：`show("bank")` → loadBank；`state.bankPage`；`#bank-search` input 事件 → 重置第 1 页 + loadBank；点击开答（returnTo="bank" 返回恢复页码）；`loadTagCategories` 补填第 4 个分类下拉
- style.css：`.bank-pager`
