## 1. 自动备份（cron 每日 03:03，保留 7 份）

`backup.sh` 需上传到服务器 `/opt/interview-assistant/backup.sh`（Workbench 文件上传），然后执行：

```bash
chmod +x /opt/interview-assistant/backup.sh
mkdir -p /opt/interview-assistant/backups
# 立即手动跑一次验证
/opt/interview-assistant/backup.sh && ls -la /opt/interview-assistant/backups/
# 安装 cron（交互编辑 crontab，加一行）：
# 3 3 * * * /opt/interview-assistant/backup.sh >> /opt/interview-assistant/backups/backup.log 2>&1
crontab -e
```

**原理**：容器内 python `sqlite3.backup()` 保证 WAL 模式下副本一致（直接 cp 会漏 -wal 内容）；`docker compose cp` 拷出到宿主 `backups/`，保留最近 7 份。

**备份下载到本地**：Workbench 文件管理 → 直接下载 `backups/interview_*.db` 即可。

## 2. MinerU 模型预热（首次解析不再卡 10 分钟）

首次上传 PDF/DOCX 会触发 ~1.2GB 模型下载。可提前预热（缓存在 hf_cache 卷，只下一次）：

```bash
docker compose exec app bash -c 'printf "hello" > /tmp/t.txt && soffice --headless --convert-to pdf --outdir /tmp /tmp/t.txt && mineru -p /tmp/t.pdf -o /tmp/mineru_out && rm -rf /tmp/t.txt /tmp/t.pdf /tmp/mineru_out'
```

耗时约 5-15 分钟（视带宽）；跑完后续 PDF 解析为秒级。

## 3. 牛客源：生产/公开实例保持关闭

牛客采集仅用于**本地个人学习**，生产/公开/多人部署实例一律不启用：

- `config.yaml` 已默认 `sources.nowcoder_enabled: false`，生产包不要改为 `true`
- 不要在服务器 `.env` 配置 `NOWCODER_COOKIE`（历史 `.env.bak` 中若残留可清理）
- 即便历史环境残留 cookie，只要 `nowcoder_enabled=false`，牛客源也不会进入流水线

本地个人学习如需启用牛客，只在本地机器改 `config.yaml` 为 `true` 并自行评估平台条款/封号风险。

## 4. 部署新代码（5 批优化后首次部署：含速率限制/判分/上传/UI 优化）

**准备**（本地）：
```powershell
tar -czf deploy_package.tar.gz --exclude=.git --exclude=.venv --exclude=data --exclude=backups --exclude=deploy_package.tar.gz --exclude="interview_backup_*.zip" --exclude="__pycache__" --exclude="*.pyc" --exclude=.env --exclude=.pytest_cache --exclude=.idea --exclude=.opencode .
```
> 注意：**必须排除 .env**（真实 API key + 牛客 cookie 不得进部署包）与 `interview_backup_*.zip`（备份包不得进代码包）；服务器上的 `.env` 由下方 `cp /root/.env.bak .env` 恢复。可用 `tar -tzf deploy_package.tar.gz | Select-String env` 验证无 `.env`。

**服务器**（Workbench 上传 deploy_package.tar.gz 后）：
```bash
cd /opt/interview-assistant
# 备份当前 .env（新包不含它）
cp .env /root/.env.bak
tar -xzf /root/deploy_package.tar.gz
cp /root/.env.bak .env
docker compose build && docker compose up -d
docker compose logs -f app   # 确认无报错
```
