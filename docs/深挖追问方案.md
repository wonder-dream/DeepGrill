# 深挖追问链（Deep-Probe Chain）实施方案

> 状态：已实施 ｜ 日期：2026-08-08 → 2026-08-09（难度分级追问：目标深度与轮次上限按难度收紧）
> 目标：追问到"不会为止"，探测思考深度与认知广度；判分深度按探到的层级校准

## 1. Prompt 重构（`CHAIN_PROMPT_V1 → V2`，app/judge/chain.py）

角色重定义：资深面试官**逐层深挖**，答对就加深，直到探到真实水平。

**五层深度阶梯**（每轮追问 ≥ 上一层）：
L1 概念/定义 → L2 原理/机制 → L3 权衡/取舍 → L4 边界/反例/极端场景 → L5 横向联系/知识广度

**每轮输出**：`{"action": "continue"|"finish", "followup", "quality": "correct"|"partial"|"wrong"|"unsure", "level": 1-5}`

**策略**：
- correct → 继续加深（除非已到 L5 且最近两轮均 correct）
- partial → 同层挖缺口或降一层确认
- wrong/unsure → **连续 2 次差评才收尾**（单次差评再给机会）

**finish 仅两种**：连续 2 次差评探到底 / L5 连续 2 轮 correct。20 轮上限兜底；降级路径保留。

## 1.5 难度分级追问（2026-08-09，CHAIN_PROMPT_V2 → V3）

**目标深度按难度映射**（`app/difficulty.py` `target_level_for`，`min(5, difficulty+1)`）：

| 难度 | 目标层级 | 语义 |
|---|---|---|
| 1 入门 | L2 | 概念+原理即可 |
| 2 基础 | L3 | 到权衡/取舍 |
| 3 进阶 | L4 | 到边界/极端场景 |
| 4 深度 | L5 | 全链深挖 |
| 5 专家 | L5 | 全链 + 答到 L5 才算证明充分 |

- prompt 注入 `题目难度：{difficulty}/5（{档位名}）` + `目标深度 L{target_level}`；finish 条件由「已到 L5」改为「已到**目标深度**且最近两轮 correct」
- **轮次上限按难度收紧**（`max_rounds_for`，`min(config_max, 3+difficulty*3)`）：难度 1→6 轮、3→12、5→18（全局 20 上限不变）
- 注入点：routes.py resume 接口与答题后台任务（`resume()` 新增 `target_level` 参数）；judge 侧无需联动（v5 难度校准已兼容）
- 低难度题判分不因探得浅而低分：depth 按实际探到的 max_level 校准（原有机制）
