# 深挖追问链（Deep-Probe Chain）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08
> 目标：追问到"不会为止"，探测思考深度与认知广度；判分深度按探到的层级校准

## 1. Prompt 重构（`CHAIN_PROMPT_V1 → V2`，app/judge/chain.py）

角色重定义：资深面试官**逐层深挖**，答对就加深，直到探到真实水平。

**五层深度阶梯**（每轮追问 ≥ 上一层）：
L1 概念/定义 → L2 原理/机制 → L3 权衡/取舍 → L4 边界/反例/极端场景 → L5 横向联系/知识广度

**每轮输出**：`{"action": "continue"|"finish", "followup", "quality": "correct"|"partial"|"wrong"|"unsure", "level": 1-5}`

**策略**：
- correct → 继续加深（除非已 L5 且最近两轮均 correct）
- partial → 同层挖缺口或降一层确认
- wrong/unsure → **连续 2 次差评才收尾**（单次差评再给机会）

**finish 仅两种**：连续 2 次差评探到底 / L5 连续 2 轮 correct。20 轮上限兜底；降级路径保留。

## 2. 层级落库

- `Attempt.level: Optional[int]` + `_migrate_attempt_level`（ALTER TABLE）
- `_persist_attempt` 记录层级

## 3. 判分联动（judge v3 → v4）

- `judge(..., max_level: int | None = None)`：chain.finish / routes retry 路径从 attempts 算最大层级传入
- `JUDGE_SYSTEM_V4` 新增"追问深度：探到 L{n}/5"；depth 按"最终能答到的层级"校准
- `PROMPT_VERSION = "judge_v4"`

## 4. 前端

- `_attempts_transcript` 的 interviewer 条目带 `level`
- 追问气泡加层级徽标（1=概念 2=原理 3=权衡 4=边界 5=拓展），CSS `.chat-level`
