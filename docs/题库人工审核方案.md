# 题库人工审核方案（2026-08-10）

> 状态：**已确认、执行中** ｜ 目的：题库 2957 题质量参差，人工逐题审核分类/标签/难度
> 决策：① 词表全部可管理（含种子）② AI 参考 = 现有标签快照（零 LLM 成本）③ 删标签连带清题上标签 ④ 批量操作 ⑤ 未审题在应用中不可见（已接受）

## 1. 词表数据库化（全量可管理）

```
tag_categories: id / name / is_custom
tag_items:      id / category_id / name / is_custom
review_suggestions: id / question_id / suggested_tags(JSON) / suggested_difficulty / suggested_category / created_at
```

- 种子 = 代码默认 13 类/81 词，启动（init_db 后）写入 DB；**全部可增删改**（is_custom 仅标识）
- `tags.py`：`TAG_CATEGORIES/TAG_VOCABULARY` 保持模块常量（初始种子），新增 `reload_tags()`（从 DB 重建常量）；启动与管理接口增删后调用
- 管理接口（require_owner）：
  - `POST /api/admin/categories`（新增分类）、`DELETE /api/admin/categories/{id}`（空分类可删，非空拒绝）
  - `POST /api/admin/tags`（新增标签，指定分类）、`DELETE /api/admin/tags/{id}`（**连带清除题上该标签**）
  - 种子分类/标签同样可删（连带清题上标签）

## 2. 标签快照 + 清空（一次性脚本）

- `scripts/snapshot_tags.py`：SELECT 每题 (tags, difficulty) → 写 review_suggestions（分类 = 首标签所属分类）→ 清空 questions.tags
- 题库回无标签状态（审核期间应用内不可筛选/复习——已确认接受）

## 3. 审核页 /static/reviewer.html（owner 入口）

- 主界面侧边栏加「题库审核」链接（仅 owner）→ 独立页
- 每题：题干 + 来源 + **AI 参考卡片**（快照分类/标签/难度，只读）+ 人工编辑区（词表选分类/标签 + 自定义 + 难度）
- 「采用 AI 建议」：快照填入编辑区；「保存」→ 写 questions 真实 tags/difficulty
- 批量：勾选多题 → 批量采用建议 / 批量保存 / 批量删除
- 筛选（分类/难度/已审状态）+ localStorage 进度
