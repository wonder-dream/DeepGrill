# 追问链对话历史 + 自动清空（方案 B）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08
> 承接：docs/修复记录.md「追问链面试官提问未展示」修复（方案 A），本方案补齐对话时间线体验

## 1. 目标

答题页展示完整对话时间线（题干 → 每轮「你的回答 / 面试官追问」），每轮提交后输入框**自动清空**，直接回答新追问。复用后端 attempts 数据，不新增存储。

## 2. 后端 `routes.py`

`session_status` active 分支新增 `transcript` 字段，复用现有 `_attempts_transcript(session_id)`（`[{role: "user"|"interviewer", content}]` 扁平序列，空 feedback 跳过）。`followup` 字段保留。

## 3. 前端

- `index.html`：`#answer-followup` 替换为 `<div id="answer-chat">`（对话历史容器）
- `app.js`：
  - `renderAnswer()` 清空 chat
  - 新增 `renderChat(transcript)`：user → "你：…"（灰底），interviewer → "面试官：…"（橙底），最后一条 interviewer 高亮 `.chat-latest`；空 transcript 且有 followup 时兜底单条
  - `pollResult` active 分支：渲染 chat + **自动清空输入框** + 状态栏提示
- `style.css`：`.chat-item` / `.chat-user` / `.chat-interviewer` / `.chat-latest`

## 4. 测试

`test_chain_multi_rounds` 补充 transcript 断言（第 1 轮 2 条、第 2 轮 4 条），followup 断言保留。

## 5. 验证

1. `uv run pytest` 全绿
2. 重启 + Ctrl+F5，真实追问链肉眼验证

## 6. 明确不做

- 流式/打字机效果
- 重新回答上一轮
- 历史会话完整复盘页
