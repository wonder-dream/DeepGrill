# 薄弱点复习 v1（SQL 标签检索版）实施方案

> 状态：已确认，待实现 ｜ 日期：2026-08-08
> 对应 DESIGN.md §9.2（薄弱点复习）；依赖共享标签词表（✅ 已完成）

## 1. 目标与范围

做完一道题 → 判分结果页的薄弱点标签（weak_tags，词表内词）可点击 → 进入该薄弱主题的复习列表（同类历史题，未做优先）→ 点击直接开始答题。

**v1 用 SQL 标签匹配，不引向量库**（词表已收敛，weak_tags ⊆ tags，SQL 命中即"同类题"）；向量检索 + hit_rate/MRR 评估留到以后升级。

## 2. 后端 `app/web/routes.py`

### 2.1 新增 `GET /api/review?tag=RAG`

- 校验 `tag ∈ TAG_VOCABULARY`，否则 400
- 查询：`SELECT questions WHERE tags LIKE '%"RAG"%'`（JSON 数组元素精确匹配，词表无引号字符，安全）
- 排序：未完成在前（done=False 优先），组内 created_at 倒序，LIMIT 30
- 每题附最新 finished 判分（复用 helper）

返回：

```json
[{ "id": 5, "stem": "...", "type": "knowledge", "difficulty": 2,
   "tags": ["RAG"], "done": false, "total_score": null }]
```

### 2.2 提取共用 helper

历史接口"每题取最新 finished session+judgment"逻辑提取为
`_latest_judgment_by_question(session) -> dict[int, tuple[Session, Judgment]]`，
history 与 review 共用（行为不变，测试兜底）。

### 2.3 实现细节

- 标签匹配：`cast(Question.tags, String).like('%"RAG"%')`；若 cast+like 在 SQLite 不生效，退化为 `text("tags LIKE :p")`

## 3. 前端

### 3.1 `index.html` 新增 `#view-review`

```html
<section id="view-review" class="view hidden">
  <div class="card">
```

### 3.2 `app.js`

- `state.returnTo = "today"` + `state.reviewTag`：从复习列表进答题时置 `"review"`，结果页「返回」改为 `show(state.returnTo)` 并重载对应视图
- 结果页（renderResult）：薄弱点从纯文本改为可点击按钮（`data-tag`），点击 → `loadReview(tag)`
- 新增 `loadReview(tag)`：拉取并渲染复习列表（badge：待做/得分/判分失败 + type + 难度 + stem），空态提示；卡片点击 → `startAnswer(item)`（复用现有流程）
- 复习循环闭环：复习题答完 → 结果页可继续点薄弱点 → 返回回到复习列表
