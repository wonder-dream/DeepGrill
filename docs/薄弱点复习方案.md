> 对应 DESIGN.md §9.2（薄弱点复习）；依赖共享标签词表（✅ 已完成）

## 1. 目标与范围

做完一道题 → 判分结果页的薄弱点标签（weak_tags，词表内词）可点击 → 进入该薄弱主题的复习列表（同类历史题，未做优先）→ 点击直接开始答题。

**v1 用 SQL 标签匹配，不引向量库**（词表已收敛，weak_tags ⊆ tags，SQL 命中即"同类题"）；向量检索 + hit_rate/MRR 评估留到以后升级。

## 2. 后端 `app/web/routes.py`

### 2.1 新增 `GET /api/review?tag=RAG`

- 校验 `tag ∈ TAG_VOCABULARY`，否则 400
- 查询：`SELECT questions WHERE tags LIKE '%"RAG"%'`（JSON 数组元素精确匹配，词表无引号字符，安全）
- 排序：未完成在前（done=False 优先），组内 created_at 倒序，LIMIT 30
- 每题附最新 finished 判分（复用 helper）

返回：

```json
[{ "id": 5, "stem": "...", "type": "knowledge", "difficulty": 2,
   "tags": ["RAG"], "done": false, "total_score": null }]
```

### 2.2 提取共用 helper

历史接口"每题取最新 finished session+judgment"逻辑提取为
`_latest_judgment_by_question(session) -> dict[int, tuple[Session, Judgment]]`，
history 与 review 共用（行为不变，测试兜底）。

### 2.3 实现细节

- 标签匹配：`cast(Question.tags, String).like('%"RAG"%')`；若 cast+like 在 SQLite 不生效，退化为 `text("tags LIKE :p")`

## 8. 复习卷 v2（2026-08-09，LLM 针对性复习讲义）

### 目标

复习列表页从「同类题列表」升级为「LLM 针对性复习讲义 + 推荐练习」，先补知识再做题。

### 后端 `GET /api/review/paper?tag=X`（同步生成 10-30s）

- 校验 tag ∈ 词表（400，同 v1）；标签级**内存缓存**（`_review_paper_cache` + 锁，命中直接返回）
- 素材：v1 SQL 标签匹配题（LIMIT 30）取 top-8（id/难度/题干）注入 prompt
- LLM（generate 模型）输出 `{"paper": "markdown 讲义", "recommended_ids": [题ID]}`
  - paper 三部分：核心知识点梳理 / 高频考点与易错点 / 答题框架与表述要点（难度分层）
  - recommended_ids：从素材题中选 3-5 道（服务端校验存在性，最多 5）
- **python-markdown 转 HTML**（`Markdown` 依赖，为富格式渲染/后续升级准备）后返回 `{paper_html, recommended_ids}`
- 素材为空 → `{paper_html: "", recommended_ids: []}`（前端提示）

### 前端（复习列表页）

- 顶部「生成复习卷」按钮（生成中禁用转圈，10-30s）→ 讲义卡片（HTML 渲染）→ 重新生成按钮
- `recommended_ids` 命中的题在列表中**置顶 + 「推荐」红色徽标**（沿用 badge-done 样式）

### 测试（+3）

`test_review_paper_generates`（markdown→HTML 断言 + 推荐 ID 在素材内）/ `test_review_paper_cached`（二次请求 LLM 调用计数 1）/ `test_review_paper_invalid_tag_400`

### 明确不做（v2）

- 判分诊断（薄弱原因分析依赖判分数据，目前不足，v3 再议）
- 讲义 DB 持久化（内存缓存够用，重启重生成）
