# 语义去重（Phase 2 §9.1）实施方案

> 状态：✅ 已完成 ｜ 日期：2026-08-08
> 对应 DESIGN.md §9.1：embedding 相似度阈值替代 LLM 语义去重

## 1. 目标

M9 去重的"LLM 语义判断"替换为 **bge-m3 embedding 余弦相似度阈值**判重；接口调用方不变（仅 M12），降级语义保持（宁重复勿丢题）。存储：**SQLite BLOB + numpy 暴力余弦**（0 新存储依赖）。

## 2. 依赖与模型

- `sentence-transformers` + torch（**GPU 版手动安装**：`uv pip install torch --index-url https://download.pytorch.org/whl/cu124`；PyPI 默认 CPU 版）
- 模型 `BAAI/bge-m3`（1024 维，2.2GB，首次自动下载；`HF_ENDPOINT=https://hf-mirror.com` 镜像）
- encode 前 L2 归一化（bge-m3 建议）

## 3. 新增 `app/embed.py`

- `Embedder`：lazy 加载模型（首次调用才加载），batch encode（batch=32），失败抛 `EmbedError`
- `ensure_embeddings(questions, embedder)`：补算 embedding 为 NULL 的题并落库（无 id 的仅写内存对象）
- 向量序列化：numpy float32 bytes（~4KB/题）

## 4. 存储

- `Question.embedding: Optional[bytes]`（BLOB 列）
- `init_db` 迁移 `_migrate_embedding`（ALTER TABLE 补列，旧题 NULL 首次自动补算）

## 5. `dedup.py` 重写

签名：`dedup(new_questions, existing_questions, embedder)`

1. 空输入短路
2. **归一化精确重复快速路径**（无需 embedding，降级模式同样可用）
3. `ensure_embeddings(existing)` 补算旧题
4. 新题 encode（写回对象，daily 落库时持久化，避免下次重算）
5. numpy 余弦 `max_sim ≥ SIM_THRESHOLD` → 判重
6. `EmbedError` → 降级仅哈希（宁重复勿丢题）

## 6. 阈值标定结论（真实模型，2026-08-08）

60 题 / 1770 对相似度统计：**最大 0.7971**，均值 0.487，p90 0.599，p95 0.633，p99 0.716。

- 真重复对（同任务改措辞）落在 0.78-0.80：如 #200 Tool/MCP schema ↔ #199 工具调用（0.797）、#185 ↔ #182 RAG 动态知识更新（0.794）
- 0.73-0.77 区间是"同主题不同题"（如三个 RAG 设计题互相 0.74-0.77），**不应判重**
- **结论：`SIM_THRESHOLD = 0.85` 保持**——实测最大 0.797，零误杀；真重复对（0.78-0.80）放过可接受（宁重复勿丢题 + D16 题量上限兜底）

## 7. 调用链

- `daily.py`：`run_daily(config, sources, llm, embedder)`
- `routes.py`：`_run_daily_pipeline` 构建真实 Embedder（lazy）
- `tests/fakes.py`：`FakeEmbedder`（预置向量表 + 可注入异常；随机向量 64 维防误撞）

## 8. 测试

- test_dedup 重写（12 用例）：归一化精确重复（零 encode）、预设向量判重/保留、阈值边界 0.84/0.86、旧题向量复用不重算、NULL 补算、embedder 降级仅哈希、批内多条、幂等
- test_daily：run_daily 补 FakeEmbedder 参数（10 处）

## 9. 实测数据（真实库）

- 首次全量 embedding：209 题 **20.1s**（RTX 4060）
- 端到端冒烟：改措辞重复题被判重 ✓；新主题题保留 ✓

## 10. 明确不做

- 向量库（sqlite-vec/chroma）题量万级再评估
- embedding 缓存表/增量重建机制（NULL 即算）
- hit_rate/MRR 评估（留给 §9.3 judge 参考检索）
