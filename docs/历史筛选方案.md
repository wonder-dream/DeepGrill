# 历史记录筛选功能 实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 1. 目标

历史页新增三组筛选：**做过/未做**、**日期（下拉）**、**高分(≥80)/低分**；高分/低分仅在"做过"下生效（细粒度筛选）。**纯前端实现，后端零改动**（`/api/history` 已返回 done/total_score/date 全部所需字段）。

## 2. 设计决策（已确认）

- **前端筛选**：~300 题规模全量已加载，客户端过滤最简单；将来量大再下沉后端
- **日期下拉**：从已加载分组的日期自动生成选项（倒序）+ "全部"
- **判分失败**（total_score=None）归入**低分**档
- **组合语义**：三组条件 AND；选"未做"时分数下拉禁用

## 3. 前端改动

### index.html

历史视图顶部加筛选栏（状态/日期/分数三个 select，分数默认 disabled）。

### app.js

- `state.historyGroups`：缓存原始分组（loadHistory 时保存）
- `loadHistory()`：拉取 → 存缓存 → 填充日期下拉 → 调 `applyFilters()` 渲染
- `applyFilters()`：done 筛选 → score 筛选（仅 done 且非 all：高分 ≥80；低分 <80 或 None）→ date 筛选（保组）→ 空组剔除 → 全空提示"无符合条件的记录"
- `#filter-done` change：未做时禁用分数下拉
- 渲染逻辑抽为 `renderHistory(groups)` 复用

### style.css

`.filter-bar`：flex 布局、label 间距。

## 4. 边界

| 场景 | 行为 |
|---|---|
| 判分失败 | done=true、分数 None → 低分档 |
| 日期下拉 | 选项 = 当前分组日期（倒序）+ 全部 |
| 无历史 | 筛选栏显示，列表空态 |
| 未做 + 分数 | 分数下拉禁用 |

## 5. 验证

- 后端零改动 → 230 测试回归
- 手工路径：未做筛选+禁用联动 / 80 分边界 / 日期单选 / 组合 AND / 判分失败归低分

## 6. 明确不做

- 后端筛选参数、日期范围、历史搜索框/题型筛选 UI
