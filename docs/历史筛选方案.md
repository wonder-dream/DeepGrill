# 历史记录筛选功能 实施方案

> 状态：已实施 ｜ 日期：2026-08-08 → 2026-08-09（日期筛选升级为右侧常驻日历范围选择；日历按视图显隐 + 今日单选）

## 1. 目标

历史页新增三组筛选：**做过/未做**、**日期（日历范围）**、**高分(≥80)/低分**；高分/低分仅在"做过"下生效（细粒度筛选）。**纯前端实现，后端零改动**（`/api/history` 已返回 done/total_score/date 全部所需字段）。

## 2. 设计决策（已确认）

- **前端筛选**：~300 题规模全量已加载，客户端过滤最简单；将来量大再下沉后端
- **日期筛选（2026-08-09 升级）**：右侧空白处内嵌**常驻日历面板**（自绘月视图，纸感档案风，复用 CSS 变量配色），点击选择开始/结束日期形成范围；有历史记录的日期右下角红点；今天红色描边。窄屏（<1100px）隐藏面板，filter-bar 保留两个原生 `<input type="date">` 兜底，双控件双向同步
- **按视图显隐（2026-08-09）**：日历仅在**今日**（单选模式：选中某天 → `GET /api/today?date=` 显示该日题目，不限 status 可回看）与**历史**（范围模式）视图展示；其余视图（题库/答题/结果/复习/详情）隐藏。今日页选中日期切页后保留，「回到今日」按钮复位。日历年月按视图**独立记忆**（`calViews[today|history]`，切换视图互不影响）；「清除范围」/「回到今日」同时把日历复位到当前月（2026-08-09）
- **年月快速选择（2026-08-09）**：点击日历顶部年月 → 弹层（年份 ◀▶ 导航 + 12 个月网格，当前月红色描边）→ 选月即跳转；点面板外关闭
- **判分失败**（total_score=None）归入**低分**档
- **组合语义**：三组条件 AND；选"未做"时分数下拉禁用

## 3. 前端改动

### index.html

- 历史视图筛选栏（状态/日期/分数三个筛选；日期为 from/to 两个 date input）
- `main` 后新增 `<aside id="calendar-panel">`：月标题 + ◀▶ 切换 + 清除范围 + 星期表头 + `#calendar-grid`

### app.js

- `state.historyGroups`：缓存原始分组（loadHistory 时保存）
- `state.rangeFrom/rangeTo`（YYYY-MM-DD 或 null）：日期范围的唯一事实源；`state.calYear/calMonth` 当前显示月；`state.historyDates` 有历史日期集合（打点）
- `renderCalendar()`：周一起始 7 列月视图；今天红描边、范围内红软背景、端点红色实心白字、历史日期红点
- 范围交互：第一击设起点，第二击设终点（早于起点自动交换），第三击重开新一轮；变化即同步两个 date input 并 `applyFilters()`
- `#calendar-clear` 清空范围；input change 反向写回 state + 重绘日历 + 过滤
- `applyFilters()`：done 筛选 → score 筛选（仅 done 且非 all：高分 ≥80；低分 <80 或 None）→ 日期范围筛选（保组）→ 空组剔除 → 全空提示"无符合条件的记录"

### style.css

`#calendar-panel`（300px 常驻、sticky、卡片风）、`.calendar-grid`（7 列）、`.calendar-cell` 各状态配色、`.filter-bar input[type="date"]` 对齐、`@media (max-width: 1100px)` 隐藏面板。

## 4. 边界

| 场景 | 行为 |
|---|---|
| 判分失败 | done=true、分数 None → 低分档 |
| 日期范围 | from/to 均为空 = 不限；from > to（input 手输）→ 只取新值重新起选 |
| 无历史 | 筛选栏显示，列表空态；日历无红点 |
| 未做 + 分数 | 分数下拉禁用 |
| 跨月范围 | 切换月份后高亮跟随当月可见部分，选择不丢失 |

## 5. 验证

- 后端零改动 → 230 测试回归
- 手工路径：未做筛选+禁用联动 / 80 分边界 / 日历范围选择与 input 双向同步 / 组合 AND / 判分失败归低分 / 窄屏 input 兜底

## 6. 明确不做

- 后端筛选参数、历史搜索框；日历月度切换只支持单月视图（不做双月/年视图）
