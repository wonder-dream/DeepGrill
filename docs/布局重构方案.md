# 布局重构方案（右侧日历面板整合统计内容）

> 状态：**已确认、实施中** ｜ 日期：2026-08-10
> 背景：用户反馈「打卡日历与右侧原有日历冗余」「今日页概览/趋势位置不合理」，要求整合进右侧日历面板。

## 结构调整

| 页面 | 右侧 calendar-panel 内容 |
|---|---|
| 今日 | 日历（圆点：有题未做=空心 ○、做过=实心 ●）+ 当日完成情况（X/Y 已答 + 进度条） |
| 历史 | 日历（范围选择）+ 答题趋势（近 14 天柱状图 + 平均分） |
| 题库 | 日历（圆点）+ 概览数字卡（题库/已完成/已答/平均分） |

- 今日页顶部三列统计面板（迷你打卡日历/答题趋势/概览）全部移除
- `calendar-panel` 内新增 `#panel-extra` 区域，按当前视图动态渲染

## 改动清单

- `index.html`：删 `#today-stats`；`calendar-panel` 日历下方加 `<div id="panel-extra">`
- `app.js`：
  - 删迷你日历/今日页 stats 触发；`loadStats` 存 `state.stats` 供 history/bank 渲染
  - `state.historyDone`（date→是否做过）由 `loadHistory` 计算；`renderCalendar` 大日历加圆点
  - 新增 `renderPanelExtra()`：today→完成情况（state.todayItems）；history→趋势柱状图；bank→概览数字
  - `show()` 联动：today→`loadToday+loadHistory`；history→`loadHistory+loadStats`；bank→`loadBank+loadStats+loadHistory`；panel 显示范围加 bank；calendarMode 加 bank 分支（点击日期跳历史筛选）
- `style.css`：
  - 删 stats-grid/迷你日历三列样式；圆点样式复用到大日历 cell（position:relative + `.cal-dot`）
  - `panel-extra` 分隔卡片样式、完成进度条
  - 修趋势日期重叠：`trend-day` 去 rotate、只显示日号（完整日期放 title）、贴柱底
- 版本号 bump `?v=20260810b` → `c`；`node --check` + 浏览器验证；后端与测试不动
