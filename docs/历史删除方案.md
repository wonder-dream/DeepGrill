# 历史记录手动删除 实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 1. 目标

两级删除（均二次确认）：**详情页删单次作答** + **历史列表删整题作答记录**；题目本身保留在题库（可重做，历史回到"未做"）。

## 2. 后端（+2 接口）

### `DELETE /api/sessions/{session_id}` — 删单次作答

- 404：会话不存在；409：正在判分中（`_inflight`）
- ORM `session.delete(row)` → relationship cascade（all, delete-orphan）级联删 attempts + judgments
- 返回 `{"deleted": true}`

### `DELETE /api/questions/{question_id}/history` — 删整题作答记录

- 404：题目不存在；删除该题全部 sessions（级联）；Question 本身不动
- 返回 `{"deleted": true}`

## 3. 前端

- 详情页：尝试区加"删除本次记录"按钮（当前高亮尝试）→ confirm → DELETE → 重新 loadDetail；删光显示"暂无作答记录"
- 历史列表：卡片加"删除"按钮 → confirm → DELETE question history → applyFilters；`stopPropagation` 防误触跳详情

## 4. 边界

- 删除 active 会话：允许（放弃该次），"进行中"徽标自然消失
- 正在判分的会话：409 拒绝
- 删除后题目保留，历史回到"未做"

## 5. 测试（+4 用例）

| 用例 | 断言 |
|---|---|
| 删单次 | attempts/judgments/session 全删（无孤儿）；题目保留 |
| 删单次 404 / inflight 409 | 不存在 404；inflight 409 |
| 删整题 | 全部会话删除；questions 表仍有该题 |
| 删整题 404 | 未知题目 404 |

## 6. 文档

- 本文档；M14 API 表补两个 DELETE

## 7. 明确不做

- 清空全部历史；删除题目本身
