# 用户上传题目（侧边栏入口）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-09

## 1. 前端

- 侧边栏底部「上传题目」按钮 → 隐藏 file input（.md/.txt）→ FileReader.readAsText → `POST /api/upload`（JSON {filename, content}，避免 python-multipart 依赖）
- 提示：直接模式"已入库 N 题"；面经模式"已提交，后台生成中…"

## 2. 后端 `POST /api/upload`

- 校验：扩展名 .md/.txt；内容 ≤2MB（UTF-8 容错）
- **格式识别**：全部非空行匹配 `^Q[:：]` 或 `^[-*]\s` 且每行 <120 字符 → 直接模式；否则面经模式
- **直接模式**：解析为 knowledge 题（难度 1、默认 criteria）→ 建 manual source（content 哈希）→ 入库；后台 LLM 补标签（≤20 题一次调用，词表过滤，失败留空）
- **面经模式**：写 data/uploads/ → import_file(manual) → 后台 `generate_source_immediately`（单源生成，不受 36 上限；非阻塞拿 _run_lock）

## 3. pipeline 新增

`generate_source_immediately(source_id, llm, embedder) -> int`：generate_from_source → dedup → 入库（复用 daily 逻辑）
