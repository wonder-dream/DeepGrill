# 页面美化（纸感极简 · 面试档案）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08
> 设计方向：面试档案/待批试卷——暖纸底、墨字、考卷红批注、衬线标题、细线分隔、大留白

## 1. 色彩体系（离开蓝色系）

| 变量 | 值 | 用途 |
|---|---|---|
| 纸底 | `#f6f4ef` + 极轻点阵纸纹（radial-gradient 24px） | 页面背景 |
| 纸卡 | `#fffdf9` | 卡片（1px 暖线，无阴影堆叠） |
| 墨色 | `#26231e` | 正文/主按钮 |
| 次墨 | `#6f6a5e` | 辅助文字 |
| **考卷红** | `#c0392b` | 分数/判分/进行中/强调（唯一强调色） |
| 橄榄绿 | `#5d7a4f` | 已答/完成 |
| 暖线 | `#e5e0d5` | 边框/分隔 |

## 2. 字体（本地系统栈，零依赖）

- 标题/日期/分数：`Georgia, "Songti SC", SimSun, serif`（衬线 = 档案感核心）
- 正文：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 分数：衬线大字（红笔书写感）

## 3. 布局与组件

- 头部：纸白吸顶 + 底部 2px 墨线 + 标题衬线 + 考卷红圆点
- 今日统计：档案抬头——大衬线红数字 + 细线 + 小字说明（去蓝色渐变卡）
- 卡片：纸白 + 1px 暖线 + 6px 圆角；hover 线变红微上浮
- 徽标：印泥感小方章（红字红边半透明）；已答橄榄绿
- 导航 active：考卷红下划线（档案标签感）
- 主按钮：墨黑底白字；删除红字红线
- 评分条：6px 细条纯红实心（无渐变）；结果总分 34px 衬线红字
- 聊天：面试官左侧红竖线 + 纸色块（批注感）；用户墨灰块
- 日期分组头：衬线日期 + 底部细线
- 留白：容器 660px、卡片间距 14px、层次加大

## 4. 动效/可访问性

- 仅 hover 0.15s 过渡；focus-visible 红环；正文对比度 ≥ 4.5:1

## 5. 改动范围

- `style.css` 全量重写；`index.html` 统计卡/头部微调；`app.js` 零逻辑改动；后端零改动

## 6. 不做

外部字体 CDN、图标库、暗色模式、复杂动画
