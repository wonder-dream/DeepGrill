# 共享标签词表（Phase 2 前置）实施方案

> 状态：已确认，待实现 ｜ 日期：2026-08-08
> 对应 DESIGN.md §9 前置："生成与判分共享标签词表"

## 1. 目标

生成侧题目标签（`tags`）与判分侧薄弱点（`weak_tags`）共用一套固定主题词表，经 **prompt 约束 + 代码过滤** 双重保证，为 Phase 2 薄弱点复习（按 weak_tags 检索同类题）打地基。

## 2. 设计决策（已确认）

- **单层主题词表**：纯主题/技术标签，生成与判分共用；薄弱点=薄弱主题（可检索同类题），能力维度由四维分数表达，不设"深度不足"类能力词
- **代码过滤**：模型输出词表外的标签一律丢弃（可测试、保证一致性），而非仅 prompt 约束

## 3. 改动清单

### 3.1 新增 `app/tags.py`（纯常量，约 70 行）

- `TAG_VOCABULARY: tuple[str, ...]`：45 个主题词（见下表）
- `tag_vocab_text() -> str`：渲染为 prompt 片段（"- Agent\n- RAG\n..."）

| 类别 | 词表项 |
|---|---|
| Agent 生态（9） | Agent、Agent框架、Multi-Agent、ReAct、Function Calling、Tool Use、MCP、LangChain、LangGraph |
| LLM 核心（12） | Transformer、Attention、Tokenizer、大模型、Prompt工程、上下文工程、微调、LoRA、量化、KV Cache、推理优化、流式 |
| RAG/检索（7） | RAG、Embedding、向量数据库、检索、重排序、文档问答、混合检索 |
| 训练/对齐（5） | 预训练、RLHF、强化学习、数据工程、模型评估 |
| 后端基础（10） | Java、Spring、MySQL、Redis、消息队列、微服务、分布式、高并发、JVM、网络 |
| 通用（7） | 系统设计、架构设计、算法、数据结构、设计模式、项目深挖、场景题 |

### 3.2 `app/pipeline/generate.py`

- `GENERATE_PROMPT_V1 → V2`、`PROJECT_PROMPT_V1 → V2`：tags 要求改为"从词表选 1-5 个，不得使用词表外的词"，注入 `{vocab}`
- `_validate_questions`：`tags = [t for t in tags if t in TAG_VOCABULARY][:5]`

### 3.3 `app/judge/judge.py`

- `JUDGE_SYSTEM_V1 → V2`：weak_tags 要求"从词表选 0-3 个薄弱主题标签"
- `PROMPT_VERSION = "judge_v1" → "judge_v2"`（`test_prompt_version_frozen` 强制同步）
- `_parse_judgment`：`weak_tags = [t for t in weak_tags if t in TAG_VOCABULARY][:3]`
