# 复习可见入口 实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08
> 背景：复习功能此前只能从"判分结果页点薄弱点标签"进入，无导航入口，用户不可见

## 1. 目标

顶部导航加「复习」按钮 → 复习入口页展示**需要加强的题目**（薄弱点标签 + 计数），点标签进入复习列表。分类筛选（题型+标签）方案随后单独执行。

## 2. 后端：`GET /api/review/tags`

```json
[{ "tag": "RAG", "count": 3 }, { "tag": "缓存", "count": 0 }, ...]
```

- 聚合全部 `judgments.weak_tags` 计数，返回**全部词表标签**（58 个）
- 排序：count>0 在前（count 降序），count=0 在后（词表顺序）

## 3. 前端

- 导航加「复习」按钮（`data-view="review"`）
- 复习视图两级：
  - 无选中标签（`state.reviewTag=null`）→ **薄弱点入口列表**：count>0 标签（红章 + 次数徽标）在前 + 全部主题可浏览；无数据提示"完成答题后这里会显示需要加强的题目标签"
  - 点标签 → 现有 `loadReview(tag)` 复习列表（返回按钮回入口）
- `loadReviewHome()` 渲染入口；导航点击/返回按钮触发

## 4. 测试

- review_tags 聚合：weak_tags ["RAG","缓存"] / ["RAG"] → RAG=2 优先、缓存=1、其余 0
- review_tags 空库：全 count=0
