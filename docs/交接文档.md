## 1. 项目一句话

个人求职准备工具：每日自动采集面经 → LLM 出题 → 深挖追问链答题 → 四维判分 → 薄弱点复习，叠加 RAG 知识库（FAISS 内存索引）注入、收藏/岗位语言个性化、人工审核工作流；邮箱验证码注册 + 邮箱登录。全本地运行（FastAPI + SQLite + bge-m3 本地向量）。

## 2. 运行方式

```bash
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000   # 启动服务（后台维护：data/logs/server.pid）
uv run pytest                                              # 377 个离线测试
uv run python -m app import 面经.md --type manual          # CLI 导入
uv run python scripts/bootstrap_generate.py                # 批量生成积压源（当前仅剩 15 个顽固源）
uv run python scripts/import_knowledge.py --distill        # 知识导入（--distill LLM 蒸馏 / --rebuild 清空重导）
uv run python scripts/collect_nowcoder_days.py             # 牛客按天批量收集（仅本地个人学习）
uv run python scripts/crawl_kamacoder.py                   # 卡码抓取
uv run python scripts/eval_retrieval.py                    # 检索评估（hit_rate/MRR）
uv run python scripts/eval_rag.py / eval_rag_gen.py        # RAG 检索层 / 生成层测评
uv run python scripts/polish_questions.py                  # 题库清洗（LLM 分类 keep/rewrite/delete，可复跑）
uv run python scripts/loadtest.py --token <token> --mode read --concurrency 20 --total 100
```

- GPU torch 已装（2.6.0+cu124）；`.env` 需配：`LLM_API_KEY`、`NOWCODER_COOKIE`（仅本地个人牛客采集；生产/公开不配）、`SMTP_HOST/SMTP_PORT/SMTP_USER/SMTP_PASS`（163 邮箱授权码，验证码用）、`OWNER_EMAIL/OWNER_PASSWORD`（owner 预置）、`ENABLE_DOCS=1`（本地调试 /docs，生产默认关）
- 浏览器用后普通 F5 即可（index.html no-store + `?v=` 版本参数，改前端后必须 bump）
- 数据备份在 Web 上传页（导出 zip / 导入恢复，导入前自动备份当前库并保留最近 5 份）；PDF/DOCX/DOC 解析需 LibreOffice + mineru（均已装）
- 旧治理脚本已删（`2654708`：migrate_tags/retag_empty_tags/migrate_difficulty/migrate_questions_from_backup，勿再引用）

## 6. 敏感信息提醒

- API key / SMTP 授权码 / cookie 只在 `.env`（已 gitignore）；交接/贴日志时注意脱敏
- 牛客采集仅限本地个人学习：`config.yaml` 默认 `sources.nowcoder_enabled=false`，生产/公开不配置；本地若开启且 cookie 过期 → 该源静默停用（日志 `disabled today`），需在本地重新获取
- token 30 天过期（B3），过期后需重新登录
- 验证码为进程内存态：服务重启后未用验证码失效，需重新获取

## 7. 给接手 agent 的提示

- 项目原则见 `AGENTS.md`（Karpathy 准则：先想后写、简洁、surgical、可追溯）
- 改动后必跑 `uv run pytest` + `node --check app/web/static/app.js`；**改前端静态资源后必须 bump `index.html` 里的 `?v=` 版本号**
- **schema 迁移在 `db.py` 的 `_migrate_*`（启动自动执行，幂等）**：现 3 个 —— `_migrate_user_picks_unique`（重建表去重）、`_migrate_sessions_active_unique`（同用户同题单 active）、`_migrate_users_email`（users 加 email 并清空用户数据，**已执行，勿再触发误清**）；重建前先 dispose 旧引擎
- **登录标识 = email（unique）**：username 仅显示名（注册自动 = 邮箱前缀，重名加后缀）；owner 预置 = `OWNER_EMAIL/OWNER_PASSWORD`
- **验证码模块 `app/email_code.py`**：内存态 + SMTP 发送（`send_smtp_code` 可 monkeypatch 测试）；同邮箱 60s 限频、5 分钟有效、5 次错误作废、用后即删；发送函数注入测试勿触网
- **Source 模型无 `raw_text`**（仅 `cleaned_text`）；标签走 `question_tags` JOIN；审核字段并入 questions
- **Embedder 进程级单例 + 双检锁**（`_default_embedder_factory` + `embed.py _load`）：勿改回每次新建（4C8G 双份 2.3GB 打满）
- **删题保护**：单删/批量删/清历史/质检删题均检查 `_inflight`（判分中 409/跳过）；`_inflight` 带 600s TTL 自动清理
- 复习卷讲义经 bleach 白名单消毒（`_sanitize_html`）；改题/删题/词表变更后自动清复习卷缓存
- 前端路由：hash 状态参数 + sessionStorage 中间态恢复；离开流程/换用户时清除
- **勿手动删除 `interview.db-shm/-wal`**（丢未 checkpoint 写入，08-10 踩坑）
- 涉及 LLM 的测试全用 `tests/fakes.py` Fake 实现；FakeLLM 下跳过 quality 筛选
- 压测：`scripts/loadtest.py`（read 并发安全；answer 触发真实 LLM，并发 ≤2，同题并发 409 属预期）
