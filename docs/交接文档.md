## 1. 项目一句话

个人求职准备工具：每日自动采集面经 → LLM 出题 → 深挖追问链答题 → 四维判分 → 薄弱点复习，叠加 RAG 知识库（FAISS 内存索引）注入、收藏/岗位语言个性化、人工审核工作流，全本地运行（FastAPI + SQLite + bge-m3 本地向量）。

## 2. 运行方式

```bash
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000   # 启动服务
uv run pytest                                              # 362 个离线测试
uv run python -m app import 面经.md --type manual          # CLI 导入
uv run python scripts/bootstrap_generate.py                # 批量清理积压源（一次性；当前 479 源待生成）
uv run python scripts/import_knowledge.py --distill        # 知识导入（--distill LLM 蒸馏 / --rebuild 清空重导）
uv run python scripts/collect_nowcoder_days.py             # 牛客按天批量收集（越过已存在 + createdAt 边界）
uv run python scripts/crawl_kamacoder.py                   # 卡码抓取（多级路径）
uv run python scripts/eval_retrieval.py                    # 检索评估（hit_rate/MRR）
uv run python scripts/eval_rag.py / eval_rag_gen.py        # RAG 检索层 / 生成层测评
uv run python scripts/polish_questions.py                  # 题库清洗（LLM 分类 keep/rewrite/delete，可复跑）
uv run python scripts/loadtest.py --token <token> --mode read --concurrency 20 --total 100  # 真并发压测
```

- GPU torch 已装（2.6.0+cu124，requirements.lock 已 pin）；`.env` 需配 `LLM_API_KEY` + `NOWCODER_COOKIE`
- 浏览器用后普通 F5 即可（index.html 已 no-store，静态资源带 `?v=` 版本参数，改前端后须 bump 版本号）
- 数据备份在 Web 上传页（导出 zip / 导入恢复，导入前自动备份当前库）；PDF/DOCX/DOC 上传解析需系统 LibreOffice + mineru 模型（均已装）
- 旧治理脚本已删（`2654708`：migrate_tags/retag_empty_tags/migrate_difficulty/migrate_questions_from_backup 等，勿再引用）
