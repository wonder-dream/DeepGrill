# 页面充实方案（打卡日历 + 答题趋势 + 统计概览）

> 背景：用户反馈登录后页面空旷（所有页面）；期望加入打卡日历与答题趋势，先全加上再精简。

## 1. 布局加宽（所有页面）

- `style.css`：`main` 的 `max-width` 660px → **880px**（宽屏不再左右空旷）

## 2. 后端：GET /api/stats（新增，per-user 隔离）

```json
{
  "bank_total": 2293,        // 题库总数（SQL count）
  "answered_total": 12,      // 该用户已判分答题数（状态 ok 的 judgment 数）
  "done_questions": 5,       // 已完成题数（每题最新判分 ok）
  "avg_score": 74.5,         // 平均分（ok 判分）
  "trend": [{"date": "2026-08-01", "answered": 2, "avg_score": 78}, ...]  // 近 30 天
}
```

- trend 按 `Session.ended_at`（status=finished + judgment 状态 ok）逐日 GROUP BY，补全 30 天空日期
- 位置：`app/web/routes.py`，与 history 同区；测试 3 个用例（聚合正确 / 空数据 30 天空 / per-user 隔离）

## 3. 打卡日历（今日页顶部）

- 数据源：**现有 `/api/history`**（按 picks 日期分组 + done 标志），无需新字段
- 圆点规则：

| 该日状态 | 显示 |
|---|---|
| 无题目（无 picks） | 无标记 |
| 有题目但全未答 | 空心圆点 ○ |
| 有题目且至少做了一道 | 实心圆点 ● |
| 今天 | 圆点 + 描边 |

- 交互：点击有题的日期 → 跳历史页并筛选该日

## 4. 答题趋势（今日页顶部）

- 近 14 天柱状图（纯 CSS div 高度，零依赖，纸感风格）：每天答题数（来自 /api/stats trend），柱上显示数字
- 附平均分一行（数字展示）

## 5. 汇总数字（今日页顶部）

- 题库总量 / 已完成 / 已答总数 / 平均分（大数字样式，复用 summary-card 风格）

## 6. 空状态美化

- 今日/题库/历史/复习列表无数据时：图标 + 引导文字 + 推荐动作占位
