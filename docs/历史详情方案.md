# 历史记录详情（问答记录 + 评分 + 多次作答切换）实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 1. 目标

历史页点开任意题目 → 查看该题**每次作答**的完整问答记录（题干 + 每轮回答/追问，含层级徽标）+ 评分（四维分数/总分/评语/参考答案/薄弱点）；多次作答用**按钮切换**。

## 2. 已确认决策

- **独立视图**：点卡片跳转 `#view-detail`，返回回历史（保留筛选状态）
- **未完成会话也显示**：尝试列表含 active 会话（标"未完成"徽标，可看已答轮次，无评分区）

## 3. 后端：新增 `GET /api/questions/{question_id}/history`

```json
{
  "id": 5, "stem": "...", "type": "knowledge", "tags": [...],
  "attempts": [
    { "session_id": 12, "kind": "chain", "status": "finished",
      "started_at": "...", "ended_at": "...",
      "judgment_status": "ok", "total_score": 86,
      "transcript": [{"role": "user", "content": "..."},
                     {"role": "interviewer", "content": "...", "level": 3}],
      "judgment": { "scores": {...}, "total_score": 86, "review": "...",
                    "reference_answer": "...", "weak_tags": [...], "reference_used": true }
    },
    { "session_id": 9, "status": "active", "judgment_status": null, ... }
  ]
}
```

- 会话按 id 倒序（最新在前）；transcript 复用 `_attempts_transcript`（含 level）
- 判分复用 `_latest_judgment` + `_judgment_payload`；failed → judgment=null
- 无会话 → attempts=[]；未知题目 404

## 4. 前端

### index.html 新增 `#view-detail`

题干 + 返回按钮 + `#attempt-tabs`（尝试按钮组）+ `#detail-chat`（时间线）+ 评分区（`#detail-scores`/`#detail-review`/`#detail-reference`/`#detail-tags`）

### app.js

- 历史卡片 click → `loadDetail(q.id)`（未做条目显示"暂无作答记录"）
- `loadDetail`：拉取 → 渲染题干 + 尝试按钮组（最新在前、当前高亮、含"未完成"徽标）→ 渲染第一个尝试
- `renderAttempt(attempt)`：transcript → 时间线（复用 renderChat 样式）；ok → 四维条+总分+评语+参考答案+薄弱点；failed → "判分失败"；active → 时间线+"未完成"
- 返回 → `show("history")` + `applyFilters()`（保留筛选）

### style.css

`.attempt-tabs` / `.attempt-tab` / `.attempt-tab.active`

## 5. 测试（+4 用例）

| 用例 | 断言 |
|---|---|
| 多次作答 | attempts 倒序、各自 transcript（含 level）与 judgment payload |
| 判分失败 | judgment_status=failed、judgment=null |
| 未完成会话 | status=active、无 judgment、transcript 为已答轮次 |
| 未做 / 404 | attempts=[] / 404 |
