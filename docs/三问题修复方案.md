# 三问题修复方案（标签筛选/分类生效/历史不同步）

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 问题 1：删除细粒度标签筛选

- index.html：三处移除"标签"下拉
- app.js：移除 tagFilter 维度、fillCategoryOptions 的标签填充、标签事件绑定、重复的 filterByTypeTag 定义
- 筛选栏简化为：题型 + 分类

## 问题 2：分类筛选重构

- 单一 `filterByTypeCategory(items, type, category)`（去标签维度 + 去重复定义）
- 分类下拉逻辑保留（词表 6 类）
- 说明：词表外标签旧题（21 题）在分类筛选下不可见属预期

## 问题 3：历史不同步（7 题 selected_at NULL）

- 新增幂等迁移 `_migrate_backfill_today_selected_at`（启动执行）：
  `UPDATE questions SET selected_at = created_at WHERE status='today' AND selected_at IS NULL`
- 效果：今日 91 = 历史 91；未来同型漂移自动兜底

## 验证

- node --check + 全量 pytest 回归
- 真实库迁移后验证 91 = 91
- 浏览器重启 + Ctrl+F5 后实测分类筛选
