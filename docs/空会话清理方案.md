# 空会话清理 + 空壳不计入统计 实施方案

> 状态：已确认，实施中 ｜ 日期：2026-08-08

## 1. 问题

第一题 17 个会话、全库 26 个"空壳"会话（无 attempts 无 judgments）——来自修复前"每次点击题目卡片都新建会话"的行为。历史详情尝试列表把它们显示为"第 N 次 未完成"，观感像"十几个空回答"。attempts 表本身无空记录（空/过短回答提交时已被 400 拦截）。

## 2. 方案（已确认：只删空壳 + 启动自动清理）

### 2.1 启动自动清理（幂等迁移，`app/db.py`）

```python
def _migrate_cleanup_empty_sessions(engine):
    # 删除既无 attempts 也无 judgments 的空壳会话；每次启动执行（幂等）
    DELETE FROM sessions
    WHERE id NOT IN (SELECT DISTINCT session_id FROM attempts)
      AND id NOT IN (SELECT DISTINCT session_id FROM judgments)
```

- 只删空壳；答过 ≥1 轮（有 attempts）或判过分的会话保留（含未完成 active）
- 只删无子行会话，不受 FK 影响；天然幂等

### 2.2 历史详情展示层兜底（`routes.py` question_history）

attempts 列表跳过 transcript 为空且无判分的会话——防御性：残留空壳也不显示。

## 3. 效果

- 真实库：第一题 17 → 1 个会话；"十几个空回答"消失
- 今日列表"进行中"徽标只反映真实有效的进行中会话

## 4. 测试（+2 用例）

| 用例 | 断言 |
|---|---|
| 迁移清理 | 空壳会话 init_db 后消失；有 attempts 的保留；跑两次幂等 |
| 接口兜底 | 空壳 + 有内容会话 → question_history 只返回有内容的 |
