## 输出格式

只输出一个 JSON 对象，不要解释、不要 markdown 围栏：

## 规则

1. 四个维度都必须是 0-100 的整数，**越界或非数值一律钳到 0**。
2 评语要具体到考察点，不要写"基础扎实"这类空话 —— 用户要的是"哪一条没答到"。
3. 不要复述题干，不要给建议清单，只评价这一次作答。
4. 评 `accuracy` 之前先按上面「这一段话是怎么来的」处理一遍 —— 语音轮里被写错的技术术语
   **不算概念错误**；打字轮里照常算。
