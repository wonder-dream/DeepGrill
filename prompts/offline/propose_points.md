## 输出格式（严格照做）

只输出一个 json 对象，不要解释、不要 markdown 围栏：

{
  "points": [
    {
      "name": "知识点名（8 字以内，是能力名不是题目名）",
      "definition": "一到两行：这个点在考什么",
      "exclusions": "什么不算这个点（没有就留空）",
      "criteria": ["考察点一", "考察点二", "考察点三"],
      "question_ids": [1, 2, 5]
    }
  ]
}
