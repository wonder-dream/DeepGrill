## 输出格式（严格照做）

只输出一个 json 对象：

```
{
  "name": "合并后的知识点名（8-20 字，名词短语，不要写成一句话）",
  "definition": "一到两行：这条知识点考什么、不考什么",
  "exclusions": "容易与它混为一谈、但**不属于**它的东西（没有就留空）",
  "criteria": ["什么算答到这一条", "另一条判据"]
}
```

## 规则（严格照做）

1. `criteria` 是**判据**，不是知识点名 —— 每条都要能用来判断"候选人答到了没有"。
   合并时取各组里最具体的说法，2-6 条。
2. 粒度由**题目**决定，不由学科决定（决策 26）：如果这组候选覆盖的题目跨了好几个
   明显不同的主题，那就说明它们不该合并 —— 此时输出其中**覆盖题目最多**的那一条。
3. 名字要能作为知识地图上的一个节点：不要出现"综合""其他""杂项"这类无法判定的词。
4. 只输出 json，不要解释、不要 markdown 围栏。
